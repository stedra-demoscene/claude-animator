# events.json

The cue sheet. Generated by the pipeline from the voice takes (scratch or real), the aligner output and footage detection.
Never edited by hand. Picture, music and SFX all read it. It is the only source of times.

All times are **seconds on the global film clock** (0 = first frame of the film).

## Format

```json
{
  "version": 1,
  "fps": 60,
  "total": 184.30,
  "lines": {
    "s1_l1": { "start": 2.10, "end": 6.84, "take": "s1_l1_03", "scene": "s1" },
    "s2_l1": { "start": 8.00, "end": 12.35, "take": "s2_l1_01", "scene": "s2" }
  },
  "words": {
    "s2_l1": [
      { "w": "It's",   "start": 8.00,  "end": 8.21 },
      { "w": "Monday", "start": 8.21,  "end": 8.72 }
    ]
  },
  "footage": {
    "invoice_send": { "clip": "invoice_send.mp4", "start": 41.43, "button": 46.23, "end": 47.03 }
  },
  "events": {
    "sheet_scroll_end": 11.9,
    "invoice_sent": 46.23,
    "dashboard_open": 51.55,
    "freeze": 58.25
  },
  "sections": {
    "s1": { "start": 0.0,   "end": 7.5 },
    "s2": { "start": 7.5,   "end": 31.0 }
  }
}
```

Fields:

| Field | Meaning |
|---|---|
| `version` | Schema version. Bump when the shape changes. |
| `fps` | Render frame rate. Times are not rounded to frames in the file. Consumers round. |
| `total` | Film length in seconds: end of the last line plus the closing hold. |
| `lines` | One entry per script line id: global start and end of the trimmed take, which take file, which scene. |
| `words` | Per line id, the forced-alignment words on the global clock. Only for lines that need word-level cues. Others may omit it to keep the file small. |
| `footage` | Per recorded clip: where it is placed on the global clock, plus detected moments inside it (also on the global clock). Include the clip's own offset in a `clipOffset` field if it starts mid-file. |
| `events` | Named moments. The main interface for everything downstream. Flat name -> seconds. |
| `sections` | Scene spans. Zero gaps between sections unless the script asks for a pause. |

## Rules

1. **Named events only.** Scene and score code says `ev("invoice_sent")`. It never writes
   `lineStart("s3_l2") + 4.8` or a bare number.
2. **Derived events are defined in the pipeline, once.** If a click lands where an animation curve crosses a
   threshold, the pipeline computes that time and writes `dial_click`. Picture and SFX both read it. Neither
   recomputes it.
3. **Names are the contract with the script.** A stage direction `{event: invoice_sent}` in `script.md` must have
   a matching key. The pipeline fails on a missing or unused name.
4. **Name by meaning, not by position.** `invoice_sent`, not `t_46`. Names survive retakes, positions do not.
5. **Anchors for the score.** Music cues name events, not seconds: `{"cue": "strings_in", "at": "invoice_sent"}` in the
   score file, resolved against this file at build time.
6. **No overlaps.** Two lines may not overlap unless the script marks them as overlapping. The validator checks
   `end <= next.start` per track.
7. **Deterministic.** Same inputs give byte-identical output. Sort keys, fixed rounding (3 decimals). Then a git
   diff after a retake shows exactly what moved.
8. **Validate on every build**: referenced events exist, events are within `[0, total]`, words lie inside their
   line, word times are monotonic, every picked take file exists.

## How a word-level event is defined

The script marks the word, the pipeline finds it:

```markdown
**s3_l4**
> Invoices go out in three clicks: draft, review, send.
*Each word lights up as spoken.* {words: s3_l4}
*The send button glows.* {event: send_glow, at: "word:s3_l4:send"}
```

`word:<line>:<text>[#n]` looks up the nth occurrence of that word (default first, case-insensitive,
punctuation stripped) in `words[<line>]` and writes its start time as `send_glow`. If the word is not found,
the build fails with the line text and the aligned words printed side by side.

## Consumer template

`templates/events.ts` is the one door to the cue sheet: `ev(name)`, `line(id)`, `words(id)`, `section(id)`, and
`waitUntilEvent(name, sceneStart)` for Motion Canvas scenes. Scenes import from it and never read the JSON directly.
`templates/scene.tsx` shows a scene using it, with captions from the words.

## Retake test

1. Change `picks.json` for one line, rebuild.
2. `git diff events.json` must show only that line's `start/end` and later times shifted, plus its words and the
   events derived from them.
3. Watch a scene that uses those events live in the editor. It must be in sync with no edits.

If this fails, the pipeline has a hidden constant somewhere. Find it with `grep` for digits in `film/` and
`score/`.
